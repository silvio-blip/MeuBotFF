## Comandos para Executar (no terminal do Codespace)

### 1. Verificar remote
```bash
git remote -v
```

### 2. Atualizar branch local
```bash
git pull origin master
```

### 3. Adicionar arquivos
```bash
git add DEPLOY.md cogs/notificacoes.py cogs/pesquisa.py cogs/ranking.py cogs/usuarios.py scripts/add_genero_idade.sql
```

### 4. Commitar
```bash
git commit -m "fix: corrige URLs da API Vercel, adiciona dados pessoais no /entrar e avatar no /perfil"
```

### 5. Push para o GitHub
```bash
git push origin master
```

## Validação
- Confirmar que o push foi feito sem erros
- Verificar no GitHub que os arquivos foram atualizados
- Confirmar que `.env` NÃO foi commitado (deve estar no `.gitignore`)

## Riscos
- `.env` contém tokens reais commitados anteriormente. Após o push, considerar rodar `DISCORD_TOKEN` e `SUPABASE_SERVICE_ROLE_KEY`.
- O `.gitignore` já protege `.env`, mas o histórico antigo pode conter tokens.
