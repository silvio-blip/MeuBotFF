# 1788700897104-api-url-fix-plan.md

## Problema
A `API_VERCEL_URL` no `.env` é a base `https://ff-id-old.vercel.app/`, mas o código concatena `?uid=...` diretamente sem o path `/api/player`. A API devolve HTML (página raiz) em vez de JSON, causando o erro de mimetype.

## Causa raiz
- `.env`: `API_VERCEL_URL=https://ff-id-old.vercel.app/`
- Código: `f"{config.API_VERCEL_URL}?uid={uid}"` → gera `https://ff-id-old.vercel.app/?uid=...`
- Correto: `https://ff-id-old.vercel.app/api/player?uid=...`

Além disso, há URLs hardcoded para `https://fire-id.vercel.app/` em `usuarios.py`, `pesquisa.py` e `ranking.py` que devem usar a mesma base.

## Decisão
Manter `API_VERCEL_URL` como base URL no `.env` e corrigir todas as chamadas para appendar o path correto.

## Tarefas

### 1. Atualizar usos de `API_VERCEL_URL` para player data
Nos seguintes ficheiros, mudar `f"{config.API_VERCEL_URL}?uid={uid}"` para `f"{config.API_VERCEL_URL}/api/player?uid={uid}"`:

- `cogs/usuarios.py` — linhas 80, 244, 387
- `cogs/ranking.py` — linhas 89, 193, 266
- `cogs/notificacoes.py` — linhas 90, 174
- `cogs/pesquisa.py` — linha 61

### 2. Corrigir URLs hardcoded para domínio correto
- `cogs/usuarios.py:418` — mudar `https://fire-id.vercel.app/api/csstats?uid={uid}` para `f"{config.API_VERCEL_URL}/api/csstats?uid={uid}"`
- `cogs/pesquisa.py:66` — mudar `https://fire-id.vercel.app/api/search?name={busca}` para `f"{config.API_VERCEL_URL}/api/search?name={busca}"`
- `cogs/ranking.py` — verificar se há outras URLs hardcoded

### 3. Validar consistência
- Confirmar que não restam URLs hardcoded para `fire-id.vercel.app`
- Confirmar que todas as chamadas usam `API_VERCEL_URL` + path

## Validação
- Testar `/perfil` com UID `7648336857` — deve retornar JSON com `basicInfo`
- Testar `/pesquisar` com nome e UID
- Testar `/ranking_guilda` se houver membros verificados
- Confirmar que `csstats` e `search` também funcionam

## Riscos
- Se `ff-id-old.vercel.app` for desativado, será necessário atualizar para o novo domínio em todos os lugares.
- A `API_VERCEL_KEY` pode precisar de atualização se o provedor mudar, mas isso é independente da URL.
